# Gestão de Usuários e Segurança

## 1. Controle de acesso

O PortfolioHUB utiliza o GitHub para armazenar e compartilhar
seu código-fonte.

Como o repositório é público, qualquer pessoa pode visualizar
os arquivos publicados. Alterações no repositório dependem
das permissões concedidas pelo GitHub.

## 2. Gestão de usuários

O acesso de colaboradores deve ser limitado às pessoas que
realmente precisam contribuir com o projeto.

Em um projeto individual, não é necessário adicionar
colaboradores sem uma necessidade concreta.

## 3. Proteção da conta

A conta GitHub deve utilizar uma senha forte e autenticação
de dois fatores.

## 4. Proteção de credenciais

Senhas, tokens, chaves privadas e outras credenciais não
devem ser armazenados no repositório público.

## 5. Versionamento

As alterações são registradas por meio de commits Git,
permitindo consultar o histórico de desenvolvimento.

## 6. Revisão de segurança

A revisão deve considerar:
- Permissões de acesso.
- Autenticação da conta.
- Arquivos publicados.
- Possíveis credenciais expostas.
- Configurações de segurança disponíveis no GitHub.

## 7. Registro de validação

Os resultados das verificações serão preenchidos após
a conferência das configurações reais do projeto.
