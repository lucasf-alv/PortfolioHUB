# Plano de Implantação do PortfolioHUB

## 1. Objetivo

Implantar e disponibilizar o PortfolioHUB como um portfólio
acadêmico e profissional, utilizando Git, GitHub, GitHub Pages
e o Google Gemini como ferramenta de apoio ao planejamento,
à implementação e à documentação.

## 2. Estado inicial do projeto

O projeto já possui uma estrutura de diretórios organizada
por semestres e disciplinas, documentação em Markdown e uma
página web desenvolvida com HTML e CSS.

O repositório utiliza Git para controle de versão e GitHub
para armazenamento e compartilhamento do código.

As funcionalidades existentes serão verificadas durante
a etapa de testes.

## 3. Etapas da implantação

### Etapa 1 — Planejamento

- Definir os objetivos da implantação.
- Identificar os recursos já implementados.
- Elaborar o plano de trabalho.
- Utilizar o Google Gemini como apoio ao planejamento.
- Registrar as decisões técnicas.

### Etapa 2 — Configuração e integração com GitHub

- Conferir a configuração do repositório.
- Verificar a publicação pelo GitHub Pages.
- Disponibilizar links para o repositório e para o portfólio.
- Organizar a documentação dos projetos.

### Etapa 3 — Gestão de usuários e segurança

- Revisar as permissões do repositório.
- Manter apenas os acessos necessários.
- Proteger credenciais e informações sensíveis.
- Revisar as configurações de segurança disponíveis.
- Documentar as medidas adotadas.

### Etapa 4 — Versionamento e compartilhamento

- Utilizar commits com mensagens descritivas.
- Utilizar tags para identificar versões.
- Documentar os procedimentos de contribuição.
- Registrar o processo de compartilhamento do código.

### Etapa 5 — Testes e publicação

- Verificar o funcionamento das páginas.
- Testar os links internos e externos.
- Conferir a navegação entre as seções.
- Verificar a publicação do site.
- Corrigir os problemas identificados.

### Etapa 6 — Documentação e apresentação

- Consolidar a documentação técnica.
- Registrar as evidências da implantação.
- Preparar uma apresentação de aproximadamente cinco minutos.
- Elaborar o relatório final em PDF.

## 4. Ferramentas

- Git: controle de versão.
- GitHub: hospedagem do código e colaboração.
- GitHub Pages: publicação do site.
- Google Gemini: apoio ao planejamento e à documentação.
- HTML e CSS: desenvolvimento da página.
- Markdown: documentação do projeto.

## 5. Segurança

Serão revisadas as permissões de acesso, as configurações
do repositório e as práticas de proteção de informações.

Nenhuma senha, token de acesso ou credencial deverá ser
armazenada no repositório público.

As medidas efetivamente adotadas serão registradas após
a verificação das configurações.

## 6. Validação

A implantação será considerada validada após a verificação
do acesso ao site, da navegação, dos links, do versionamento
e das configurações de compartilhamento e segurança.

Os resultados dos testes serão documentados.

## 7. Evidências

Serão reunidas evidências como:

- Link do repositório.
- Link do site publicado.
- Histórico de commits e tags.
- Capturas de tela das configurações relevantes.
- Conversas com o Google Gemini.
- Resultados dos testes.
- Link da apresentação final.
