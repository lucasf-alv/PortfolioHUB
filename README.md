# PortfolioHUB

Repositório acadêmico e profissional desenvolvido durante minha formação em Engenharia de Software no CEUB.

O PortfolioHUB tem como objetivo centralizar atividades acadêmicas, projetos, códigos, documentações e materiais desenvolvidos ao longo da minha formação.

## Sobre

Sou estudante de Engenharia de Software no CEUB e utilizo este repositório para organizar e versionar minha evolução acadêmica e prática na área de tecnologia.

Já cursei 6 semestres de Engenharia da Computação na UnB, experiência que contribuiu para minha formação em programação, estruturas de dados, fundamentos de computação e desenvolvimento de sistemas.

## Objetivo

O PortfolioHUB foi criado para:

* Organizar atividades acadêmicas;
* Documentar projetos;
* Versionar arquivos utilizando Git;
* Centralizar materiais e documentos;
* Registrar a evolução dos projetos;
* Apresentar experiências práticas de desenvolvimento;
* Disponibilizar uma página pública utilizando GitHub Pages.

## Versionamento

O projeto utiliza Git para controle de versão.

A evolução do PortfolioHUB pode ser acompanhada pelo histórico de commits, que registra a criação da estrutura do projeto, desenvolvimento da página inicial, aprimoramentos e inclusão da documentação dos projetos.

A primeira versão formal do portfólio foi marcada com a tag:

```text
v1.0.0
```

## Organização acadêmica

A pasta `academico/` foi criada para organizar os conteúdos desenvolvidos durante a graduação.

Cada semestre possui um diretório próprio, permitindo separar atividades, exercícios, projetos e materiais de acordo com o período acadêmico.

## Documentação

A documentação dos projetos está disponível dentro de suas respectivas pastas em `projetos/`.

Além disso, a pasta `docs/` será utilizada para armazenar documentos relacionados ao desenvolvimento e à apresentação do portfólio.
