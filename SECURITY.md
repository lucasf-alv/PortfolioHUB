# Política de Segurança — PortfolioHUB

## Objetivo

Definir práticas básicas para proteger o código, as informações
e o acesso ao repositório PortfolioHUB.

## Escopo

Esta política aplica-se ao repositório acadêmico PortfolioHUB
e aos arquivos publicados no GitHub.

## Práticas de segurança

- Não armazenar senhas, tokens ou chaves privadas no repositório.
- Não publicar informações pessoais desnecessárias.
- Revisar as alterações antes de enviá-las ao GitHub.
- Manter a conta GitHub protegida com autenticação de dois fatores.
- Conceder acesso de escrita somente a pessoas autorizadas.
- Revisar periodicamente as permissões do repositório.
- Corrigir problemas de segurança identificados.

## Comunicação de vulnerabilidades

Problemas de segurança devem ser comunicados de forma
responsável ao proprietário do repositório, evitando a
divulgação pública de informações sensíveis antes da análise.

## Tratamento de credenciais

Caso uma credencial seja exposta, ela deverá ser revogada
ou substituída imediatamente. Remover o arquivo do repositório
não garante que a credencial tenha deixado de estar exposta.

## Revisão

Esta política será revisada conforme o projeto evoluir.
