# 6º Semestre

Este diretório reúne as atividades, exercícios, projetos e materiais desenvolvidos durante o 6º semestre de Engenharia de Software no CEUB.

## Disciplinas

- Big Data
- Computação em Nuvem
- Desenvolvimento Mobile
- Sistemas Operacionais
- Temas Sociais Contemporâneos
- Teste e Qualidade de Software

## Organização

Cada disciplina possui seu próprio diretório, permitindo organizar os materiais acadêmicos de acordo com a disciplina correspondente.
