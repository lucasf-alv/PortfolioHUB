# 5º Semestre

Este diretório reúne as atividades, exercícios, projetos e materiais desenvolvidos durante o 5º semestre de Engenharia de Software no CEUB.

## Disciplinas

- Arquitetura de Software e Sistemas
- Banco de Dados NoSQL
- Bootcamp 3
- Ciência de Dados e Inteligência Artificial
- Desenvolvimento Frontend
- Linguagens Formais e Autômatos

## Organização

Cada disciplina possui seu próprio diretório, permitindo organizar os materiais acadêmicos de acordo com a disciplina correspondente.
