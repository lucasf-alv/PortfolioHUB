# 4º Semestre

Este diretório reúne as atividades, exercícios, projetos e materiais desenvolvidos durante o 4º semestre de Engenharia de Software no CEUB.

## Disciplinas

- Algoritmos e Estrutura de Dados
- Desenvolvimento Back-end
- Gestão de Projetos
- Integração DevOps
- Probabilidade e Estatística
- Segurança Cibernética

## Organização

Cada disciplina possui seu próprio diretório, permitindo organizar os materiais acadêmicos de acordo com a disciplina correspondente.
