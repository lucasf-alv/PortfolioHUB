# 2º Semestre

Diretório destinado à organização das disciplinas, atividades, exercícios, trabalhos e materiais desenvolvidos durante o segundo semestre da graduação em Engenharia de Software no CEUB.

## Disciplinas

* Álgebra Linear e Geometria Analítica
* Banco de Dados 2
* Desenvolvimento de Interfaces
* Diálogo e Reflexões Éticas
* Engenharia de Requisitos
* Programação Orientada a Objetos

## Organização

Cada disciplina possui um diretório próprio para armazenar seus respectivos materiais e atividades.

```text
2-Semestre/
├── Algebra-Linear-e-Geometria-Analitica/
├── Banco-de-Dados-2/
├── Desenvolvimento-de-Interfaces/
├── Dialogo-e-Reflexoes-Eticas/
├── Engenharia-de-Requisitos/
├── Programacao-Orientada-a-Objetos/
└── README.md
```

## Objetivo

Organizar e versionar os materiais acadêmicos desenvolvidos durante o semestre, facilitando a consulta e o acompanhamento da evolução acadêmica.
