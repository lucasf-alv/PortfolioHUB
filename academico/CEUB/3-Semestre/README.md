# 3º Semestre

Este diretório reúne as atividades, exercícios, projetos e materiais desenvolvidos durante o 3º semestre de Engenharia de Software no CEUB.

## Disciplinas

- Análise e Projeto de Sistemas
- Bootcamp 2
- Cálculo para Computação
- Desenvolvimento Web
- Metodologia de Desenvolvimento de Sistemas
- Redes de Computadores

## Organização

Cada disciplina possui seu próprio diretório, permitindo organizar os materiais acadêmicos de acordo com a disciplina correspondente.
