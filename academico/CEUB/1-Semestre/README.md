# 1º Semestre

Diretório destinado à organização das disciplinas, atividades, exercícios, trabalhos e materiais desenvolvidos durante o primeiro semestre da graduação em Engenharia de Software no CEUB.

## Disciplinas

* Banco de Dados 1
* Bootcamp 1
* Engenharia de Software
* Fundamentos de Engenharia
* Introdução à Computação
* Lógica de Programação

## Organização

Cada disciplina possui um diretório próprio para armazenar seus respectivos materiais e atividades.

```text
1-Semestre/
├── Banco-de-Dados-1/
├── Bootcamp-1/
├── Engenharia-de-Software/
├── Fundamentos-de-Engenharia/
├── Introducao-a-Computacao/
├── Logica-de-Programacao/
└── README.md
```

## Objetivo

Organizar e versionar os materiais acadêmicos desenvolvidos durante o semestre, facilitando a consulta e o acompanhamento da evolução acadêmica.
